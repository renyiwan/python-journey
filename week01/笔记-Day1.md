## 二、我卡住的 3 个地方

（每个写：当时怎么想的 → 错在哪 → 正确的是什么）

### 卡点 1：动作的结果要用 `=` 接住

- **我当时的写法**：`input("输入一句英文")` 单独一行；还有一次写成 `words = input`（漏了 `()`）
- **我以为**：`input` 自己会把结果留在那儿，后面直接用就行
- **其实**：`input` / `split` 是**动作**，干完就走，结果必须有人接住。`=` 不是"等于"，是"把右边装进左边盒子"（**assign** v. 赋值）
- **正确**：`sentence = input("输入一句英文：")`　→　`words = sentence.split()`
- **验证过**：`print(sentence.split)` 会打出 `<built-in method split>` —— 那是方法**本身**，不是切好的词。加 `()`（**call** v. 调用）才是"现在就干"

### 卡点 2：文字要加引号，数字不用

- **我当时的写法**：`name = 任恩溥`（漏引号）→ `NameError`；`day = "2"`（数字加了引号）→ 能跑但类型错
- **我以为**：引号是装饰
- **其实**：引号是"这是文字"的标记。不加引号，Python 会把它当**变量名**去找，找不到就 `NameError`（**name** 名字 + **error**）
- **规矩**：文字（**string** n. 字符串）加引号；数字（**int** n. 整数）光秃秃，别加
- 遗留：`day="2"` 还没改掉，第 3 次复现（10/11）必须改成 `day=2`

### 卡点 3：算完要写回本子，不新建临时变量

- **我当时的写法**：`for w in counts`（遍历了**空本子**，应该遍历 `words`）；`tom = counts.get(w,0)+1`（新建临时变量，没写回）
- **我以为**：算出来放哪儿都行
- **其实**：`counts[w]` 是"本子的第 w 格"，`counts` 是"整个本子"。等号左边必须写清楚**写回哪一格**，不然整个本子就被换成一个数字了
- **正确**：`counts[w] = counts.get(w, 0) + 1`
- **`get(w, 0)` 两个参数各管一摊**（**parameter** n. 参数）：
  - `w` = 查哪个词
  - `0` = **查不到时的默认值**（**default** adj. 默认的）
  - 翻译：查得到给真的，查不到给 0。因为第一次遇到一个词时本子里还没有它，次数该算 0，再 +1 变 1
  - **不写那个 0 会崩**：`None + 1` → `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'`（**None** = 空；**TypeError** = type 类型 + error）
- **还栽过**：建空本子写成 `counts = [w]` → 应是 `counts = {}`。`[]`（**square bracket**）建的是列表，`{}`（**curly brace**）建的才是字典

### 附：两个低级坑（不是不会，是手滑）

1. **`for` 后面漏冒号** —— `for w in words:` 那个冒号是"下面缩进的都归我管"的开关
2. **中文标点** —— `print（counts）` 用了全角括号 → `SyntaxError: invalid character '（' (U+FF08)`。输入法切英文标点（Ctrl+.）

## 三、一句话总结（今天最值钱的那句）

> **Python 里，带 `()` 的是动作，不带 `()` 的是东西。**

- `input()` `split()` `len()` `print()` → 带括号，是**动作**，要"现在就干"
- `counts` `words` `w` → 不带括号，是**东西**（容器/变量）

`sentence.split` 不叫，拿到的是方法本身；
`sentence.split()` 才叫，拿到的是切好的一排词。

---

## 四、三个括号，各管一摊

| 括号 | 英文 | 干什么 |
|---|---|---|
| `()` | parenthesis / round bracket | **干活**：函数、方法、print |
| `[]` | square bracket | **取位置**：`words[0]` 第 1 个 |
| `{}` | curly brace / brace | **挖坑 / 建字典**：f-string 的 `{name}`、`counts = {}` |

---

## 五、方括号里放什么：编号方式不同

- **列表 `list`** 用**数字**编号，从 0 开始：`words[0]` `words[1]`
- **字典 `dict`** 用**词（钥匙）**编号：`counts['hello']`

`counts[w]` 里的 `w` 是**变量**，循环每跑一轮它就换一个词 —— 这是最难理解的一点。
