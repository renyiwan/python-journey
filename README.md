## 【项目卡 #01】

- **周次**：W1
- **技术点**：变量 / f-string / input / split / len / for 循环 / dict 计数 / 读文件
- **解决什么问题**：给一段英文文本，自动统计每个单词出现几次（想知道一篇文章高频词的人用）
- **最小版本**：读 `sample.txt`，输出完整词频字典 `{'python': 3, 'love': 2, ...}`
- **难点与解法**：
  1. `counts = counts.get(w,0)+1` 漏写 `[w]` → 整个字典被覆盖成整数 → `AttributeError: 'int' object has no attribute 'get'`。解法：分清「整个本子 `counts`」和「本子里某一格 `counts[w]`」
  2. `input()` 的结果没用 `=` 接住 → 用户输入丢失。解法：带 `()` 的动作干完会递出结果，必须用 `=` 接
  3. 中文全角括号 `（）` → `SyntaxError: invalid character`。解法：写代码时输入法切英文，或开「中文模式用英文标点」
  4. 复现第一遍把计数存进新变量 `tom` 而非写回本子。解法：算完必须写回 `counts[w]`
- **运行方式**：`cd week01 && python step2.py`
